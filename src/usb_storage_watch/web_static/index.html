USB STORAGE WATCH

Connect to USB Storage Watch

Enter the management token stored on the host computer.

Where do I find my token?

Open a terminal on the host computer, or connect to it through SSH, and run:

sudo cat /var/lib/usb-storage-watch/management.token

Copy the displayed token and paste it into the field above.

HTTP does not encrypt your token. Use HTTPS or a properly configured trusted VPN, and never expose this interface through public port forwarding.
