# UI37 — Companion setup

Integrations now presents the active network URL (or localhost when network access
is disabled), existing dashboard management-token controls, the complete public CA
PEM with Copy/download, and the bundled unchanged Companion 0.2.6 archive.
Unavailable network URLs cannot be copied. Setup also works without registered
drives. No management token is returned by the page or automatically replaced.

The unused Companion v1 and standalone standby bearer APIs, token issuers/verifiers
and restricted-token UI were removed after tracing dashboard/module references.
Historical token files remain private and untouched for rollback but no supported
route reads or accepts them. Current module actions still use dashboard sessions,
CSRF, pinned identities, review snapshots and recovery/storage locks. The recovery
and boot engines are unchanged.

Validation uses isolated storage/Docker/systemd fixtures: current authentication,
obsolete-token rejection, CSRF, public assets, shared standby/refusal, multidrive
routing, removal and recovery/unmount locks. Chromium checks cover 320/768/1440 px,
URL/port changes, missing addresses/assets, LAN disabled and full PEM copying.
The unchanged module HTTP client also logs in and reads setup/status over verified
Gunicorn HTTPS. No physical control operation or new Companion runtime test is
implied by these checks. Installer checks use private roots; no device test is
needed for this setup-only update.

Install the Debian package with `sudo apt install ./usb-storage-watch_2.0.0~ui37_all.deb`.
Back up configuration/state and retain UI36 before installation. Install only with
no active recovery/storage operation. The installer preserves saved settings and
management credentials; dashboard sessions reconnect after service restart.
Open Integrations, download/import 0.2.6 in Companion, then use the displayed URL,
existing management token and complete public CA. Existing module buttons stay.
Rollback code with `sudo apt install --allow-downgrades ./usb-storage-watch_2.0.0~ui36_all.deb`;
no configuration restore or token replacement is required for this update.
